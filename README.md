## Frontend Bootcamp Website - Bootstrap 5

Simple one-page website for a fake bootcamp.

## Description

This project is a simple one-page website built using Bootstrap 5. It includes various sections such as a navbar, showcase, newsletter sign-up, information cards, FAQ accordion, instructor profiles, and a contact section with a map.

## Features

- Responsive design using Bootstrap 5
- Navbar with links to different sections
- Showcase section with a call-to-action button
- Newsletter sign-up form
- Information cards with different themes
- FAQ accordion
- Instructor profiles with social media links
- Contact section with a map

## Usage

To use this project, simply open the `index.html` file in your web browser.
